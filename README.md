IT

Un gioco di memoria fatto su browser che si concentra sulla memorizzazione la sequenza dei colori, a disposizione l utente avra' varie modalita', tra la piu' facile fino alla piu' difficile, piu' e' difficile piu' colori da memorizzare ci saranno. Buona fortuna per l'ultima difficolta'.

EN

A browser‑based memory game focused on remembering a sequence of colors. The user can choose between multiple difficulty levels, from the easiest to the hardest — and the harder it gets, the more colors there are to memorize. Good luck with the final difficulty.
